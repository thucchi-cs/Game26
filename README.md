# Dave's Diner
A point-and-click escape room game playable on the web. In this game, you are stuck in Dave the Duck's diner. You must navigate your way around the diner, interact with Tom the Bot, and find clues to escape!

## Link
[Playable game](https://thucchi-cs.github.io/Game26/)

## Clues
***Only check here when you're stuck! Don't cheat!***

**Beginning:** Look for anything that might be crooked or misplaced

**Coin 1:** Might be in another room

**Coin 2:** You can't break the ground with your bare hands, can you?

**Coin 3:** Anyone following the rules?

**Coin 4:** What was on the eggs again?

## How It Was Made
The game was originally made by Thuc Chi Do ([thucchi-cs](https://github.com/thucchi-cs)) and Ronin Gambill ([Ronin-the-Barbarian](https://github.com/Ronin-the-Barbarian)).

### Code
This game was entirely coded with Python using the Pygame library. We utilized Object Oriented Programming. It was converted to be playable on the web using the Pygbag library. It is deployed on Github Pages
